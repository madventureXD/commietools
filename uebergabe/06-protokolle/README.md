# Fortschritts- und Prüfprotokolle

Hier werden abgeschlossene Meilensteine oder umfangreiche Prüfungen chronologisch dokumentiert. Geeignete Inhalte sind beispielsweise:

- Abschluss einer Suite oder eines größeren Tools,
- Migrations- und Upgrade-Ergebnisse,
- Lizenz- oder Sicherheitsprüfungen,
- Performance- und Barrierefreiheits-Baselines,
- Release-Vorbereitungen.

Dateinamen verwenden `YYYY-MM-DD-kurzer-titel.md`. Ein Protokoll enthält nur belegte Ergebnisse und verlinkt auf relevante Commits, ADRs oder Konzepte.
